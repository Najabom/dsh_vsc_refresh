spec 可以是 npm 包名（从 registry 解析）、本地路径、git 地址或 tarball；安装由 harness 内嵌 pnpm 执行，进度实时刷新；遇到 incompatible-version 拒绝可按提示「授予版本豁免并重试」（等价 dsh plugin allow-version）。
