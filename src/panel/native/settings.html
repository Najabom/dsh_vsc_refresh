插件包（bundle）管理走 harness 的 pluginManager，与官方 web 的插件面板同一机制：启停、按需安装、更新、市场检索都在这里。
spec 可以是 npm 包名、本地路径、git 地址或 tarball；安装由 harness 内嵌 pnpm 执行，进度实时刷新；遇到 incompatible-version 拒绝可按提示「授予版本豁免并重试」（等价 dsh plugin allow-version）。
说明：客户端 UI 类 bundle（如 drop-caret、webview-clipboard）只在浏览器 web GUI 里渲染，VS Code 面板里不生效；工具 / 模型 / 命令 / 预设 / 团队等其余插件与 web 共用同一个 harness，两边都生效。
