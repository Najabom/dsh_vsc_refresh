## 想重拍或新增

- 重拍：直接覆盖同名文件即可，README 自动生效（不需要改 README）。
- 新增：把文件放本目录，然后在 README 截图区补一块 `<p align="center"><img .../></p>`。
- 规范：图源清晰（≥ 2× 显示宽度）；`width` 只调宽度、高度自动；竖长图居中单独成行；别带真实 API key / 路径 / 隐私内容。
